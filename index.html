dNLab

released · ongoing

A distributed platform for designing and deploying virtual network labs with Containerlab. Start on one node, scale transparently across many, and share collaborative labs with built-in RBAC.

Public releases are available; active development continues.

FLiNOS

in development

A Debian-based network appliance for practical Layer 2 and Layer 3 workflows, with a Junos-style CLI for candidate configuration, comparison, commit, rollback, and verification. Designed to become a virtual device for dNLab.

Not production-ready. Compatibility with dNLab is a target, not yet certified.
